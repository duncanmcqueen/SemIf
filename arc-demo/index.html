What these numbers do—and do not—mean

Conditional probabilities. Scores are a softmax over only the displayed option logits. They are not calibrated confidence and do not include every answer the model might prefer.

Choices can sit on a near-tie. BF16 arithmetic differs between GPU vendors and execution paths. Small logit differences can flip. The repository documents this drift for the A770.

Real local timing. The server times prefill, suffix passes and full forwards in the current request. No canned results appear.

One device. The scorer requires exactly one visible GPU per server process, matching the repository rule for reproducible timing.
